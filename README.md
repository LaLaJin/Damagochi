# 우리 집 고슴도치

집에서 아프리카 피그미 고슴도치를 키우는 사육 시뮬레이션이에요. 레벨이나 미니게임 같은 게임 요소 없이, 실제 고슴도치의 생활 리듬과 사육 방법을 그대로 따라가요. 설치 없이 브라우저에서 바로 실행되고, 휴대폰 홈 화면에 앱처럼 추가할 수 있어요.

## 실행하기

- `index.html`을 브라우저로 엽니다.
- 홈 화면 앱(PWA)으로 쓰려면 정적 서버로 띄웁니다.
  ```bash
  python3 -m http.server 8000
  # http://localhost:8000 접속 → 브라우저 메뉴에서 "홈 화면에 추가"
  ```

## 무엇이 들어 있나요?

**3D**: 방, 케이지, 고슴도치가 모두 입체 모형이에요. 고슴도치는 줄무늬 가시 2천여 개, 뾰족한 주둥이, 반짝이는 코와 눈, 네 다리로 만들었고, 걸을 때 몸을 틀어 방향을 바꿔요. 화면을 끌어서 돌려 보고, 두 손가락이나 마우스 휠로 확대할 수 있어요. "따라가며 보기"를 누르면 카메라가 고슴도치를 따라다녀요.

**집**: 창문(실제 시간의 하늘)과 벽시계가 있는 방이에요. 바닥에 케이지가 있고, 안에는 종이 베딩, 이글루 은신처, 원판형 쳇바퀴, 사료 그릇, 물그릇, 온도계가 있어요. 위에는 세라믹 히터가 달려 있어요. 

**실제 생활 리듬**: 실제 시계를 따라 낮(7~19시)에는 은신처에서 몸을 말고 자고, 밤에는 나와서 사료를 먹고 물을 마시고 쳇바퀴를 달려요(하룻밤 수 km). 쳇바퀴 위에 똥을 싸서 발에 묻히기도 해요. 앱을 꺼 두어도 최대 3일까지 시간이 흐르고, 다시 열면 그동안의 기록을 보여 줘요.

**측정값**: 체중(g, 저울로 재야 알 수 있어요), 케이지 온도(°C), 사료 그릇(g), 물그릇(ml), 그리고 포만감, 수분, 청결, 신뢰도, 건강, 손톱 상태.

**돌보기 효과**: 12가지 돌보기마다 실제 동작이 3D로 보여요. 계량컵으로 사료 붓기, 물병으로 물 따르기, 핀셋으로 밀웜 내려 주기(고슴도치가 다가와 먹어요), 삽으로 똥 치우기, 새 베딩 뿌리기, 손바닥으로 들어 올리기, 거실 바닥에 내려놓기, 주방 저울에 올려 숫자 올라가는 것 보기, 손 위에서 손톱깎이로 깎기, 대야에서 거품 목욕, 서서히 데워지는 히터 전구, 이동장에 넣어 동물병원 다녀오기. 고슴도치는 그릇, 은신처, 쳇바퀴, 케이지 벽을 통과하지 않고 돌아서 다녀요.

**돌보기**: 사료 채우기, 물 갈기, 밀웜 주기(하루 2~3마리), 똥 치우기, 베딩 교체, 손에 올리기, 거실 산책, 체중 재기, 손톱 깎기, 목욕, 히터 켜기·끄기, 동물병원.

**실제 고슴도치처럼 반응해요**
- 처음 온 고슴도치는 경계심이 많아요. 손에 올리면 공처럼 몸을 말았다가, 기다려 주면 "후웁" 하고 이마 가시를 세운 뒤 천천히 몸을 풀어요. 매일 저녁 조금씩 만져 주면 신뢰도가 쌓여요.
- 낮에 깨우면 스트레스를 받아요.
- 생후 8~12주는 가시갈이 시기라 예민하고, 빠진 가시가 베딩에 보여요.
- 새 냄새를 맡으면 침 거품을 가시에 바르는 "안팅"을 해요.
- 케이지가 20°C 아래로 오래 내려가면 동면을 시도해요(위험). 히터를 켜고 손으로 데워 주거나 병원에 데려가야 해요.
- 베딩이 오래 지저분하면 진드기가 생길 수 있고, 간식을 많이 주면 과체중이 돼요.
- 나이는 현실의 하루가 1주처럼 흘러서, 생후 8주에서 약 18일이면 다 자라요(적정 체중 약 380g).

**기록**: 관찰 일지, 체중 그래프(나이별 적정 범위 표시), 쳇바퀴 누적 거리, 사육 가이드.

저장은 브라우저(localStorage)에 자동으로 되고, 앱을 업데이트해도 키우던 고슴도치는 그대로 이어져요. 예전 게임 버전(도치 키우기, 도치 대모험)에서 키우던 고슴도치도 이름과 데려온 날을 그대로 가져와요.

## 파일

- `index.html`: 앱 전체 (HTML/CSS/JS 한 파일)
- `vendor/three.min.js`: 3D 그래픽 라이브러리 three.js r128 (MIT 라이선스, `vendor/three.LICENSE`)
- `manifest.webmanifest`, `icon.svg`: 홈 화면 앱 설정과 아이콘
- `sw.js`: 오프라인에서도 열리도록 캐시하는 서비스 워커
