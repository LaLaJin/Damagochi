# 도치 대모험 🦔

고슴도치를 데려와 키우고, 미니게임으로 놀고, 탐험을 보내 보물을 모으는 다마고치 게임이에요. 초등학생이 혼자서도 즐길 수 있게 만들었어요. 설치 없이 브라우저에서 바로 실행되고, 휴대폰 홈 화면에 앱처럼 추가할 수 있어요.

## 실행하기

- 가장 간단한 방법: `index.html`을 브라우저로 엽니다.
- 홈 화면 앱(PWA)으로 쓰려면 정적 서버로 띄웁니다.
  ```bash
  python3 -m http.server 8000
  # http://localhost:8000 접속 → 브라우저 메뉴에서 "홈 화면에 추가"
  ```
- GitHub Pages: 저장소 Settings → Pages에서 이 브랜치의 루트를 배포하면 어디서나 플레이할 수 있어요.

## 무엇을 할 수 있나요?

**진짜 고슴도치처럼**: 도치는 옆모습의 실제 고슴도치 모습이에요. 줄무늬 가시 수백 개, 뾰족한 주둥이, 늘 킁킁거리는 코를 가졌고, 걸어가는 방향을 바라봐요. 아기 때는 실제처럼 하얗고 짧은 가시로 시작하고, 잘 때와 겁날 때는 공처럼 몸을 말아요. 새 냄새를 맡으면 침 거품을 가시에 바르는 "안팅"도 해요.

**돌보기**: 배부름, 기분, 청결, 체력, 건강 5가지 상태가 실시간으로 줄어들어요. 밥주기, 목욕, 응가 청소, 재우기, 약 먹이기로 돌봐 주고, 도치를 터치하면 쓰다듬을 수 있어요. 앱을 꺼 두어도 시간은 흘러요(최대 3일).

**레벨과 진화**: 무엇을 하든 경험치가 쌓여 Lv.30까지 올라요. 레벨이 오르면 새 놀이와 탐험 장소가 열리고, Lv.12에는 무엇을 제일 많이 해 줬는지에 따라 진화해요.

| 진화 | 조건 | 능력 |
|---|---|---|
| ⚡ 번개 도치 (차콜색) | 놀이를 많이 함 | 밀웜 사냥 시간 +3초 |
| 🍽️ 먹보 도치 (시나몬색) | 밥을 많이 먹음 | 배부름이 천천히 줄어요 |
| 🧭 탐험가 도치 (초콜릿색) | 탐험을 많이 감 | 탐험 시간 20% 단축 |
| 🍬 솜사탕 도치 (알비노, 빨간 눈) | 쓰다듬기·목욕을 많이 받음 | 기분이 천천히 줄어요 |

**놀이 3종** (최고 기록 저장)
- 🐛 밀웜 사냥 (Lv.1): 밀웜을 터치! 1초 안에 연속으로 잡으면 콤보, 5콤보마다 점수 2배·3배. 황금 밀웜은 3점, 벌을 누르면 -5점.
- 🍎 사과 받기 (Lv.3): 화면을 끌어서 도치를 움직여 과일을 받고 돌멩이를 피해요. 하트 3개.
- 🃏 짝맞추기 (Lv.5): 카드 6쌍을 최대한 빨리 맞춰요.

**탐험과 보물 도감**: 도토리 숲(Lv.2), 반짝 개울(Lv.4), 박쥐 동굴(Lv.7), 무지개 꽃밭(Lv.10)으로 탐험을 보내면, 실제 시간이 지난 뒤 열매와 보물을 가지고 돌아와요. 보물은 20종(일반·희귀·전설)이고, 새 보물 5개마다 보너스를 받아요.

**매일 할 거리**: 오늘의 미션 3개(올클리어 보너스), 연속 출석 보상, 밤(19시~5시)에는 놀이 열매 1.5배(고슴도치는 야행성!).

**상점**: 열매로 간식과 꾸미기(리본, 들꽃 핀, 선글라스, 밀짚모자, 왕관)를 사요.

저장은 브라우저(localStorage)에 자동으로 되고, 예전 「도치 키우기」 저장 데이터도 그대로 이어져요.

## 파일

- `index.html`: 게임 전체 (HTML/CSS/JS 한 파일, 외부 라이브러리 없음)
- `manifest.webmanifest`, `icon.svg`: 홈 화면 앱 설정과 아이콘
- `sw.js`: 오프라인에서도 열리도록 캐시하는 서비스 워커
