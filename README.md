# 도치 키우기 🦔

아기 고슴도치를 데려와 돌보고 키우는 다마고치 게임입니다. 설치할 것 없이 브라우저에서 바로 실행되고, 휴대폰 홈 화면에 앱처럼 추가할 수 있어요.

## 실행하기

- 가장 간단한 방법: `index.html`을 브라우저로 엽니다.
- 홈 화면 앱(PWA)으로 쓰려면 정적 서버로 띄웁니다.
  ```bash
  python3 -m http.server 8000
  # http://localhost:8000 접속 → 브라우저 메뉴에서 "홈 화면에 추가"
  ```
- GitHub Pages: 저장소 Settings → Pages에서 이 브랜치의 루트를 배포하면 어디서나 플레이할 수 있어요.

## 놀이 방법

| 상태 | 떨어지면 | 채우는 방법 |
|---|---|---|
| 배부름 | 기분과 건강이 떨어져요 | 밥주기 (사료는 무제한, 사과·딸기·밀웜은 상점에서) |
| 기분 | 시무룩해져요 | 쓰다듬기, 고슴도치 직접 터치, 밀웜잡기 놀이 |
| 청결 | 건강이 떨어져요 | 목욕, 응가 치우기 |
| 체력 | 0이 되면 혼자 잠들어요 | 재우기 (다 자면 스스로 일어나요) |
| 건강 | 낮으면 병에 걸려요 | 잘 돌봐 주기, 아플 땐 약 먹이기 |

- **실시간으로 흘러가요.** 앱을 닫아 두어도 시간이 지나고(최대 3일까지 계산), 다시 열면 그동안 있었던 일을 알려 줘요.
- **성장**: 돌볼 때마다 성장 점수가 쌓여 아기 → 꼬마 → 어른 고슴도치로 자라요. 클수록 가시가 많아져요.
- **밀웜잡기**: 20초 동안 나타나는 밀웜을 터치해 잡으면 열매를 얻어요. 황금 밀웜은 3점! 고슴도치는 야행성이라 밤에 놀면 열매가 1.5배예요.
- **조심!** 너무 많이 콕콕 찌르면 "후웁!" 하고 몸을 동그랗게 말아요. 간식(딸기·밀웜)을 하루 4개 넘게 주면 배탈이 나요.
- **꾸미기**: 열매로 리본, 들꽃 핀, 밀짚모자, 왕관을 사서 씌워 줄 수 있어요.

저장은 브라우저(localStorage)에 자동으로 됩니다.

## 파일

- `index.html` — 게임 전체 (HTML/CSS/JS 한 파일, 외부 라이브러리 없음)
- `manifest.webmanifest`, `icon.svg` — 홈 화면 앱 설정과 아이콘
- `sw.js` — 오프라인에서도 열리도록 캐시하는 서비스 워커
